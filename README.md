### About

I run development at **Build Right Studios** in Bangalore. I built the **Helix Roleplay** FiveM server, and most of my work now is **Madura Scripts**, a catalogue of 50+ FiveM resources for Qbox, QBCore and ESX servers. Alongside that I build Discord bots, including **Flawless**, a security bot that protects servers against nukes, raids and abuse, plus the web and desktop tools that communities and teams rely on.

I'm studying for a BCA in Cybersecurity at Kristu Jayanti College. It shapes how I write code: checks happen on the server, every action is logged, and inputs are treated as untrusted.

- **Now:** shipping new Madura resources: dispatch, garage, crafting, DMV school and server stats
- **Open source:** contributing fixes back to [Qbox](https://github.com/Qbox-project)
- **Portfolio:** [aaronwilliams.in](https://www.aaronwilliams.in)

### FiveM

**Helix Roleplay**: a FiveM roleplay server I built.

**Madura Scripts** is my resource catalogue. Each resource detects the framework automatically, uses ox_lib, and ships with an in-game admin or editor panel where it makes sense.

| Resource | What it does |
|---|---|
| **Madura Dispatch** | A dispatch core with a cd_dispatch-compatible API, a light and dark alert rail and a full dispatch panel. Your existing scripts raise the calls. |
| **Madura Garage** | Garages, impounds, walk-in interiors, purchasable garages, persistent vehicles and built-in vehicle keys. |
| **Madura Crafting** | Crafting benches drawn in the game world (DUI) with a queue, blueprints, durability, XP and community projects. |
| **Madura Shop** | Player-owned 24/7 stores: buy a shop, stock it, hire staff and run restock deliveries. |
| **Madura Siren System** | Sirens and lights synced through entity state bags, with a rotary dial HUD. |
| **Madura Admin Commands** | 127 admin commands with radius, all, job and multi-player targeting. |
| **Madura UI** | A soft-glass UI kit that also stands in for ps-ui, bl_ui, ox_lib, qb-menu and the esx UIs. |
| **Madura MiniGames** | A standalone pack of 30 minigames with an export API. |
| **Madura XP System** | Levelling with an XP ring HUD and an animated level-up card. |
| **Madura Rental V2 · Taxi Job · DMV School** | Job and service systems for Qbox using ox_target and lation_ui. |

They also cover HUDs, a pause menu, loading screens, chat, scoreboards, a killfeed, carry, safezones, waypoints, hunting, a vehicle wipe, a recoil system and more.
